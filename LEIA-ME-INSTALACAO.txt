VIZAN ENGENHARIA — VERSÃO CORRIGIDA
===================================

1. ONDE COLOCAR OS ARQUIVOS
- XAMPP: copie a pasta Vizanengenhariatest para C:\xampp\htdocs\
- O painel agora é dashboard.php (o antigo dashboard.html foi removido porque continha PHP e não era executado como PHP).
- A pasta final deve ficar, por exemplo:
  C:\xampp\htdocs\Vizanengenhariatest\
- Não separe os arquivos PHP, CSS, JS e imagens: eles usam caminhos relativos.

2. BANCO DE DADOS
- Inicie Apache e MySQL no XAMPP.
- Abra http://localhost/phpmyadmin
- Importe o arquivo usuariovizan.sql desta pasta.
- Ele cria um banco NOVO chamado usuariovizan_v2.
- O banco antigo usuariovizan não é apagado nem alterado.
- config.php já está configurado para o padrão XAMPP (root sem senha).
  Se seu MySQL tiver outra senha/usuário, altere $dbuser e $dbpass em config.php.

IMPORTANTE SOBRE OS DADOS ANTIGOS:
O SQL antigo tinha uma tabela usuario com campos incompatíveis e senha sem hash.
Este pacote cria um banco novo para evitar apagar ou misturar os dados antigos.
Os registros antigos não são migrados automaticamente. Se o banco antigo ainda existir e você quiser copiar orçamentos, descrições e imagens, faça backup e execute MIGRAR_DADOS_ANTIGOS.sql no phpMyAdmin. Esse script NÃO migra usuários, pois as senhas antigas não estavam protegidas com hash. Crie novamente o administrador pelo instalador.

3. CRIAR O PRIMEIRO ADMINISTRADOR
- Com Apache e MySQL ligados, abra:
  http://localhost/Vizanengenhariatest/instalar_admin.php
- Preencha nome, login, e-mail e uma senha forte (mínimo 10 caracteres).
- Depois acesse:
  http://localhost/Vizanengenhariatest/vizanelogin.html
- Entre com o login/e-mail e senha cadastrados.
- APÓS CRIAR A CONTA, APAGUE instalar_admin.php da pasta do servidor.

4. TESTAR O FORMULÁRIO DE ORÇAMENTO
- Abra http://localhost/Vizanengenhariatest/vizane.html
- Preencha e envie o formulário.
- A confirmação aparece na própria página.
- Entre no dashboard e abra “Solicitações de orçamento”.
- O registro deve aparecer com status “Pendente”.

5. O QUE FOI AJUSTADO
- Login SQL, verificação de senha e sessões.
- Redirecionamento e proteção do dashboard PHP.
- API alinhada ao banco de dados.
- Cadastro inicial seguro de administrador.
- Orçamento: assunto incluído no INSERT e validação dos campos.
- Envio assíncrono do orçamento com mensagem na página.
- Dashboard: listagem, filtros, status, exclusão e detalhes da mensagem.
- Conteúdo: leitura pública das descrições salvas no painel.
- Imagens: upload, listagem, exclusão e exibição na seção Projetos.
- Usuários: listagem com login, cadastro e exclusão protegida.
- Perfil: edição de nome/e-mail e alteração de senha.
- Proteção CSRF nas operações administrativas.
- Proteção básica da pasta uploads contra execução de scripts no Apache.

6. REQUISITOS
- PHP 8.0 ou superior recomendado.
- Extensões PDO MySQL, Fileinfo e mbstring habilitadas.
- MySQL/MariaDB.
- Apache com suporte a .htaccess (para a regra de uploads).
- Em hospedagem Nginx, configure a proibição de execução de scripts na pasta uploads no servidor.

7. OBSERVAÇÕES IMPORTANTES
- O conteúdo editado no painel atualiza os textos de descrição selecionados no site.
  O painel não altera automaticamente todos os títulos, telefones, endereços ou textos estáticos.
- As imagens cadastradas no painel são exibidas como cartões adicionais em “Projetos”.
- A conta Editor tem acesso de consulta; Administrador pode alterar conteúdo, imagens,
  status e usuários.
- Antes de publicar na internet, configure credenciais próprias, HTTPS e backups.
